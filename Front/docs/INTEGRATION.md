# 接口接入与验收边界

## 当前协议

接口前缀 `/api/v1`。成功响应 `{data,meta}`，meta.request_id必填；集合data必须为数组且meta.total为数字。错误显示后端error.code/message/details及request_id。请求只发送Schema声明字段，金额用字符串，时间使用RFC3339，日期以店铺时区Asia/Shanghai解释。

登录信息只在当前标签页sessionStorage保存访问令牌，刷新可恢复。退出调用后端撤销当前会话并清理本地。后端仍需逐请求校验用户当前角色、状态、会话、资源归属和专项权限；前端限制不是安全边界。

编辑必须有当前version。批量素材审核使用每项expected_version。模态表单在请求不确定失败时保留当前幂等键；修改请求体则更换键。若关闭窗口后再次提交，将是新的业务操作；媒体提交连接不确定时，应先去任务列表查询，不能反复新建计费任务。

所有AI生成和媒体生成按202受理，前端不根据按钮点击直接宣布“已生成”。商品详情任务页及任务窗口读取真实状态与事件；取消不承诺第三方停止计费。

## 已明确的接口缺口

1. **运营人员可生成图片/视频，但不能读取模型配置。** 现有契约的 `GET /settings/model-configs` 仅admin，而生成请求又要求model_config_id。前端保持权限要求：管理员从真实配置下拉选择；运营人员填写管理员提供的真实配置编号。没有自创一个能绕过权限的读取接口。建议后端阶段新增安全的generation-options，只返回启用模型的ID、名称、模式与能力，排除地址和密钥引用；需先修订契约后实现。
2. **库存列表只有sku_id，缺少SKU名称和product_id。** 前端保留真实库存列表与编号，在商品内部提供完整SKU管理；没有拼接虚构SKU名称。建议后端后续提供只读库存展示DTO以避免逐条查SKU。
3. **平台授权为占位。** 界面明确显示占位说明，只保存安全元数据，不生成真实OAuth或索取平台Token/Cookie。
4. **图片/视频供应商未选定。** 前端按能力配置提交参数，不承诺某供应商一定支持任意尺寸/时长。必须由后端返回MODEL_CAPABILITY_UNSUPPORTED等具体错误。

这些项目不通过前端假数据绕过。契约中单轮单选、预算总额、库存并发、日期口径、版本冻结等跨对象规则必须在后端事务中验证。

## 后端上线后优先验证

- 管理员、运营和查看人员分别登录；确认用户管理、审核、投放确认及实验状态的权限。
- 真实创建店铺/商品/SKU、上传原图、增量库存调整；重复键不重复加库存。
- 建轮次→诊断→选定版本→创意至少3候选→选用→媒体生成→人工审核。
- 任务失败、超时、取消、重试和迟到结果；存储恢复不重复创建素材。
- 确认建议后用确认响应版本生成实验，再确认并人工记录开始/结束。
- 经营数据仅选一个粒度；重复记录冲突；除零返回null，ROAS不冒充ROI。
- 导入预览无业务写入，提交再次校验；部分成功明确行号，重复提交不重复调整库存。
- 复盘引用数据版本，完成本轮并采纳具体动作创建第二轮。
- 真实模式不能自动降级demo；非空环境不能初始化演示数据。
- MinIO签名URL须能被浏览器访问，不应返回仅容器内部可解析的主机名。

## 验证范围

当前单元测试隔离验证请求头、路径、网络/版本错误、文件上传、请求Schema、权限声明和可访问表单标签。浏览器验收覆盖公开工作台、登录入口、静态使用指引及响应式导航；未创建假用户或注入虚构商品绕过登录。真实业务闭环需要可用FastAPI后端及对应账号，因此尚未作集成通过声明。
