# 界面设计与页面职责

采用 framed-sheet 方向（seed 1441843937），无重抽。绿灰框架、白色工作面、1px边界，无静止卡片阴影、渐变、虚构增长曲线。浅绿只在标识、选中线和真实状态上使用；核心操作深色，次级操作描边或文字。IBM Plex Sans本地加载，中文使用系统中文字体；编号使用IBM Plex Mono。

商品运营闭环是本产品的识别元素：工作台呈现建档→诊断→创意→审核→投放→复盘，商品详情用共享轮次切换和11个标签承载实际工作，避免所有功能堆在首页。

| 页面 | 首先回答的问题 |
|---|---|
| 工作台 | 当前有哪些待处理事项和活跃轮次？ |
| 商品列表 | 该进入哪个商品继续运营？ |
| 商品档案 | 资料、SKU、库存和竞品是否完整？ |
| 轮次 | 本轮依据是什么，何时可以结束？ |
| 诊断 | 本轮选用了哪一版商品判断？ |
| 主图/脚本/标题 | 哪个表达方案值得采用？ |
| 任务 | 当前执行到哪里，失败后如何处理？ |
| 素材 | 哪些真实文件已审核可用？ |
| 链接 | 本轮入口和点击统计是什么？ |
| 投放/实验 | 哪份建议已确认，哪个实验实际在运行？ |
| 经营/复盘 | 数据说明什么，下一轮采纳什么动作？ |
| 导入 | 哪些行可提交，哪些失败，是否已经入库？ |
| 管理 | 谁能操作，系统如何调用模型和后台任务？ |

1440px采用228px侧栏、24px内容间隔和8px外侧留白；中小屏折叠导航，390px为单列布局；数据表在自己的容器内滚动，页面不横向溢出。所有表单、错误和审批按钮有明确中文标签。手机导航关闭时inert，防止键盘焦点进入不可见侧栏。

业务数据全部来自真实接口。页面只有静态流程说明、枚举和契约默认值；没有需要“替换成真实数据”的业务样例。管理员手动演示初始化仍属于真实API写操作，与浏览器内mock完全区分。
